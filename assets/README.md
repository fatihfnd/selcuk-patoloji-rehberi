Bu klasördeki dosyalar sitede `assets/` altında yayınlanır.

Üniversite logosu: resmi logo dosyasını (tercihen SVG ya da şeffaf zeminli PNG) üniversitenin kurumsal kimlik
sayfasından indirip buraya `selcuk-logo.png` (veya .svg) adıyla koyun, ardından `site.yaml` içindeki `logo:` satırının
başındaki `#` işaretini kaldırın. Logo site başlığında ve yazdırılan rapor / şablon / rehber başlıklarında görünür.
Kullanım üniversitenin kurumsal kimlik kurallarına uygun olmalıdır.
